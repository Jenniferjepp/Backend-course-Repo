# Introduction to Back-End Development (DA559A)

Your own repo for the course: exercises, weekly reports and the two labs all live here. Start by creating your own
copy of this template, then pull new material from it each week.

The week plan (what to prepare, the Friday agenda, deadlines) is in Canvas; it links to the exercises and articles
here.

## Get started

1. Create your own repo from this template and clone it.
2. Add the template as `upstream`, once:

   ```bash
   git remote add upstream <url-of-this-template>
   ```

3. Each week, pull the new material:

   ```bash
   git pull upstream main
   ```

## Who writes what

The weekly pull only works without conflicts if you keep to this split.

| The teacher updates (do not edit) | You write |
|---|---|
| `README.md`, `doc/`, `exercise/` | everything else: your code, the labs, `report/` |

The report templates in `report/` are given once at the start and never updated by the teacher, so they are yours to
fill in.

## Directories

| Directory | Contents |
|---|---|
| `doc/` | Articles and reading instructions for each week |
| `exercise/` | Exercises, one directory per exercise, instructions only |
| `report/` | Your weekly reports, one file per week |
