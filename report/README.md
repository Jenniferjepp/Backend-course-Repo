# Weekly reports

One report per week, `week-01.md` to `week-06.md`. Write the week's report at the end of the week, when the exercises
are done and the week is still fresh.

The report is your own reflection on the week, not a test. Go back through the week's exercises, lectures and the
Friday session to remind yourself what you did, then write about what stuck: what was new, what was hard, and what
became clear along the way. Write in English, about one A4 page. Add pictures, diagrams and code examples if you like:
save pictures in `report/img/` and link to them from the report, for example `![The server in the browser](img/week01-hello.png)`.

The week page in Canvas ends with a few points under **Weekly report** that bring out the most important parts of the
week and can help you get started. You do not need to cover all of them, and you do not need to follow the order: a
coherent text is better than answers to questions.

Commit and push the report like any other file.
